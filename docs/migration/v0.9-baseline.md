# v0.9 Compatibility Baseline

This snapshot protects both the published v0.9 legacy CLI and the unreleased
`qa-native` surface already present when the Persona Runtime roadmap was
adopted.

## Public commands

`playwright-spec-for-ai-agent` keeps these commands and exit behavior:

- `spec`
- `abstract-ai`
- `judge`
- `review`
- `slack`
- `nightly`
- `--help` exits `0`
- an unknown command exits `1`

The package also exposes the existing `qa-native` binary and module exports.

## Frozen artifacts

- `scripts/fixtures/legacy-golden/current-behavior.json` freezes representative
  parser, annotation, fixture precedence, live-policy, skip, and always-run
  behavior.
- `scripts/__tests__/package-pack-smoke.test.ts` freezes the required npm
  tarball entry points and runtime files.
- Hermes normalization and stateless-home cleanup remain pure tests and do not
  require the Hermes binary.

## Baseline evidence

Recorded on 2026-07-26 before workspace migration:

```text
pnpm install --frozen-lockfile  PASS

```

## Release baseline

- release-please package path: `.`
- npm package: `playwright-spec-for-ai-agent@0.9.0`
- publish command: `npm publish --provenance --access public`
- runtime requirement: Node.js 20 or newer

Workspace migration must update the release-please package path and publish
working directory together. A tarball that depends on workspace-only paths is
not releasable.
